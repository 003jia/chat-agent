# TC-summary-003 空会话生成摘要报错不崩

| 字段 | 值 |
|---|---|
| 用途 | requirement |
| 覆盖范围 | 会话摘要（空会话边界） |
| 运行命令 | `npm run test:e2e:summary`（待接入） |
| 关联 spec | `e2e/specs/summary.spec.ts`（待落地） |
| 账号/登录方式 | 管理令牌登录（临时令牌 + 临时数据根 `.e2e-tmp`） |
| 清理方式 | 隔离数据根，无持久化副作用 |

## 前置条件

- 前后端已拉起；登录态已建立
- 通过 API 建一个空会话（无消息）并切换到该会话

## 步骤

1. 通过接口创建空会话 `POST /api/conversations`
2. 前端切换到该空会话
3. 触发「生成摘要」（聊天区按钮或摘要面板「重新生成」）
4. 观察页面行为

## 预期结果

1. 页面不崩溃（锚点：页面主体 `.desktop-workbench` 仍可见）
2. 出现错误提示（锚点：`.error-banner` 或状态栏提示含「摘要生成失败」）
3. 后端返回 `400 EMPTY_CONVERSATION`（由 spec 内 `page.route` 或响应断言交叉复核）

## 数据清理说明

空会话由用例创建，结束删除会话文件（隔离数据根内）。
